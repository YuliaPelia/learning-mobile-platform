# Картинка → ассет без фону

Для обкладинок курсів є окремий `add-course-image`. Цей — для маскотів та ілюстрацій на прозорому фоні.

1. Знайди файл зображення (шлях у повідомленні; скриншоти кладуться в `/private/tmp/.../images/`). Дізнайся розмір і кольори: `python3 -c "from PIL import Image; im=Image.open(P); print(im.size, im.getpixel((5,5)))"` (потрібен лише Pillow; numpy/scipy може не бути).
2. **Накладки** (кнопки «розгорнути», «пошук», напис «AI modified») зазвичай у нижніх кутах: обріж їх або затри прямокутником у масці — не перемальовуй, інакше зламаєш об'єкт.
3. **Прибрати фон** — заливка з країв (BFS) з порогом по сусідніх пікселях: крок `< 4–7`, відстань до кольору фону `< 60–75`, для кольорового фону додатково діапазон каналу. Світлий фон і світлий предмет: поріг крок ≤ 4, перевір превʼю. Результат `mask` → `putalpha`.
4. **Перевір на фоні застосунку** (лавандовий `#7C6CF2`), а не на білому: так видно ореол. Лікування ореолу: `MinFilter(3)` + `GaussianBlur(0.8)` по масці.
5. Обріж по `getbbox()`, зменш `thumbnail((480, 560))`, збережи PNG у `assets/<назва>/`. Підключай через `require('../../assets/...')` у компоненті з пропорцією `height/width` з реального файлу.
6. Покажи користувачеві результат у застосунку на симуляторі (скриншот), а не лише файл.

Обмеження: емоцію обличчя на растровій картинці міняти не вдасться без редактора зображень; можна замалювати деталі шерсті сусідніми пікселями й намалювати нові через `ImageDraw` з суперсемплінгом ×4 — для малих правок, не для реалізму. Права на зображення — на користувачеві; не додавай чужі логотипи й бренди.
