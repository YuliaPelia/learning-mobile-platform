# Стиль і токени

Усі кольори, радіуси й тіні — лише з `src/theme/index.ts`. Hex/rgba прямо в компонентах — помилка (виняток: щойно доданий токен).

## Елементи
- **Тло екрана** — компонент `Screen` (градієнт `screenGradient`). Не став `backgroundColor` екранам.
- **Скляна картка** (вторинний вміст, статистика): `backgroundColor: colors.card`, `borderWidth: 1`, `borderColor: colors.border`. **Без `shadow`** — на напівпрозорому тлі тінь на iOS просвічує.
- **Світла картка** (головна дія, «Сьогодні»): `colors.paper`, текст `colors.ink` / `colors.inkMuted`.
- **Акцент**: `colors.primary` (бузковий); текст і іконки на ньому — `colors.onPrimary` (не білий — не проходить контраст).
- **Текст** на тлі: `colors.text`, другорядний `colors.muted`. Заголовки секцій — `sectionTitle`.
- Іконки — `@expo/vector-icons` Ionicons, не емодзі.

## Доступність
- Контраст тексту ≥ 4.5:1; перевіряй нові пари кольорів.
- Цілі натискання ≥ 44×44 (`hitSlop` для дрібних).
- `accessibilityRole` + `accessibilityLabel` для `Pressable` і іконок без тексту.
- Уникай фіксованої висоти для блоків з текстом — великий шрифт обріже текст; використовуй `minHeight`/padding.

## Перевірка
`grep -rnE "'#|rgba\(" src --include='*.tsx'` має знаходити лише обґрунтовані винятки.
