# Стиль і токени

Усі кольори, радіуси й тіні — лише з `src/theme/index.ts`. Hex/rgba прямо в компонентах — помилка (виняток: щойно доданий токен).

## Елементи
- **Тло екрана** — `Screen` (градієнт `screenGradient` + світлі плями). Не став `backgroundColor` екранам. Нових варіантів `Screen` немає: сторінка курсу теж у цьому стилі (`light` — токени для неї).
- **Скляна картка**: `backgroundColor: colors.card` (або `colors.glass`), `borderWidth: 1`, `borderColor: colors.border`, радіус `radius.md/lg`. Без `shadow` на прозорих картках — на iOS тінь просвічує.
- **Біла картка** (головна дія): `colors.paper`, текст `colors.ink` / `colors.inkMuted`.
- **Акцент**: `colors.primary` — білий; текст на ньому `colors.onPrimary` (фіолетовий, 7.5:1).
- **Нижня панель** — плаваюча скляна (`BlurView` з `expo-blur` + `colors.tabBar`), активна вкладка — «таблетка» навколо іконки. Екрани, що не вкладки (курс, таймер, квіз), живуть у стеку `(tabs)/(learn)` — панель завжди видима; не виносити їх у корінь.
- `Screen` має `paddingBottom: 120` під панель; нові прокручувані екрани без `Screen` повинні мати такий самий відступ.
- Іконки — Ionicons; маскот — `Robot` (`assets/robot`), ілюстрації готуй за скілом `prepare-image-asset`.

## Доступність (обов'язково)
- Контраст тексту ≥ 4.5:1 (великий ≥ 3:1). УВАГА: білий на світлій частині градієнта дає ~1.9:1 — не ставити дрібний текст у верх екрана без темнішої підкладки. Перевіряй `ui-a11y-auditor`.
- Цілі натискання ≥ 44×44 (`hitSlop` рахується).
- `accessibilityRole` + `accessibilityLabel` для `Pressable` й іконок без тексту.
- Не фіксуй висоту блоків з текстом (`minHeight` замість `height`).
- Анімацій багато (маскот, пульсація) — поважай `reduceMotion`.

## Перевірка
`grep -rnE "#[0-9A-Fa-f]{6}|rgba\(" src | grep -v src/theme` має знаходити лише обґрунтовані винятки.
