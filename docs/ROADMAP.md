- **Наслідок:** поки немає синхронізації, вихід = втрата цих даних (користувача про це попереджає діалог). Серверний прогрес (уроки, XP, серія) не страждає.
- **Потрібно зробити:** синхронізація з сервером, після чого прибрати попередження. План:
  1. Бекенд `../itcodecraft-platform`: таблиці/ендпоінти `/api/mobile/v1/study/*` — задачі, сесії фокусу, результати квізів (+ відповіді для повторення помилок), цілі дітей. Скіл `new-mobile-endpoint`.
  2. Клієнт: `store.ts` стає кешем над API (черга офлайн-змін, злиття за `id`/часом); міграції за скілом `storage-migrations`.
  3. Квізи — з БД (створює викладач/менеджер), тестовий квіз `src/data/quizzes.ts` видалити.
  4. Після синхронізації: перевірити, що чистка при виході не втрачає даних (спершу відправити чергу, потім стерти), оновити `data-privacy-auditor`.
